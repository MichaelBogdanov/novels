# День в «Мире юрского периода»

Визуальная новелла по работе: **Мирослав**. 30 сцен, 28 иллюстраций, 11 концовок.

## Запуск

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe main.py stories/jurassic_day/story.json
```

Также доступна в библиотеке при запуске `python main.py`.

Пробел или ЛКМ раскрывает текст и продолжает историю. Стрелки / колесо выделяют вариант, Enter или ЛКМ подтверждают его. «Назад» возвращает к предыдущему шагу, Tab открывает журнал, H скрывает интерфейс, F11 переключает полный экран. «Истории» открывает библиотеку, «Выход» закрывает игру.

## Пакет

- `story.json` — сюжет, выборы и концовки.
- `art/` — готовые игровые иллюстрации 1600 × 900.

Пути ресурсов относительны папке JSON. Для переноса достаточно этих файлов. Исходные работы и материалы производства в репозиторий не включены. Сюжетные действия и последствия сохранены при литературной редактуре; иллюстрации созданы с помощью генерации изображений.

Проверка пакета: `python main.py stories/jurassic_day/story.json --validate`.

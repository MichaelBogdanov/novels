# Три двери — Полина Степанова

Адаптация текстового квеста. Запуск: `.\.venv\Scripts\python.exe main.py stories\enchanted_castle\story.json`.

Отступы исходника ошибочно связывают некоторые финалы с выбором реки, а зелье запрашивается дважды. В адаптации три финала связаны с одним выбором зелья согласно описанию сюжета. Приворотное зелье названо эликсиром, снимающим чары, в соответствии с его действием в исходной хорошей концовке. Иллюстрации созданы встроенным imagegen в мультяшном стиле.

# Необычный день в лесу — Матвей

Визуальная новелла по истории Матвея. Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe main.py stories\forest_rescue\story.json
```

Исходная программа не содержит ввода и ветвлений: она предлагает угадать дальнейшее событие и сразу сообщает ответ. В адаптации вопросы стали интерактивными: все ответы приводят к одному авторскому продолжению. Сохранены встреча с Айболитом, помощь спасателей, происшествие в больнице и возвращение домой. Ошибочный вариант «вы споткнётесь» в последнем вопросе уточнён как «вы упадёте», поскольку спотыкается герой до вопроса.

Автор не указал стиль рисунков; выбран мягкий мультяшный стиль детской книги. Семь иллюстраций созданы встроенным imagegen, приведены к 1600×900. Это сказочная история, а не инструкция по оказанию медицинской помощи.

# Две смены — Маша

Две главы, 81 сочетание маршрутов, девять итоговых финалов. Первая глава всегда продолжается новой сменой, как в оригинале. Все содержательные варианты else представлены явными кнопками. Название «Онфим» сохранено из исходника.

26 реалистичных иллюстраций созданы встроенным imagegen, по одному отдельному кадру для каждой сцены. Все изображения имеют размер 1600×900 (16:9). Показаны укрытие в шкафу, реакция вожатой, возвращение в комнату, последствия происшествия, объяснительная, возвращение на урок, новая смена, обе компании и девять финалов.

Тяжёлые травмы переданы без натуралистичных подробностей: ракурсом от лица героя и сценами помощи. Последствия в тексте сохранены, включая потерю руки. Во второй главе герой остаётся за камерой, поэтому изображения не противоречат этой ветке. Несколько последовательных действий из комментариев объединены в один ключевой кадр сцены: например, вызов помощи и возвращение на занятия завершаются кадром урока с повязкой.

Исходная программа проверяется отдельно от новеллы: для всех 81 сочетаний ответов сравниваются промежуточные и итоговые исходы. Автоматическая проверка настоящим движком использует окна 1280×720, 640×480 и 1920×1080, проверяет текстовые страницы, выбор мышью и клавиатурой, возврат и перезапуск. Это отрисовка через SDL dummy, а не полное ручное прохождение. Служебные сценарии проверки, промпты и отчёты остаются локальными.

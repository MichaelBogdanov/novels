# Авторы и ресурсы

Сюжеты основаны на работах учеников. Авторы указаны в названиях и README каждой истории. Авторские развилки и последствия сохранены при адаптации. Иллюстрации подготовлены с помощью генерации изображений.

## Звук печати

`vn/assets/typing.wav` — обработанный `tick_002.ogg` из набора [Interface Sounds](https://kenney.nl/assets/interface-sounds), Kenney, версия 1.0 (2020).

Лицензия исходного звука: **CC0**. Оригинальный текст сохранён в [vn/assets/Kenney-License.txt](vn/assets/Kenney-License.txt).

Обработка: моно, 44 100 Гц / 16 бит; однополюсный фильтр нижних частот 1800 Гц, плавные края 1,5 / 4 мс и пиковая амплитуда 2400 из 32767. Длительность около 23 мс. Громкость дополнительно регулируется `settings.volume` истории. Обработка убирает резкие высокие частоты; отсутствие наложения сохраняет ровную громкость при быстрой печати.

Лицензия CC0 относится к этому звуковому ресурсу; она не задаёт лицензию остальных материалов проекта.

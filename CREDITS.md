# Авторы и ресурсы

Сюжеты основаны на работах учеников. Авторы указаны в названиях и README каждой истории. Авторские развилки и последствия сохранены при адаптации. Иллюстрации подготовлены с помощью генерации изображений.

## Звук печати

Стандартный звук синтезируется движком: короткий синусоидальный тон 740 Гц длительностью 30 мс с квадратичным затуханием. Внешние звуковые файлы для него не требуются. Громкость задаётся через `settings.volume`; собственный WAV/OGG можно подключить через `settings.typing_sound`.

## Визуальные источники

Для истории Мирослава см. [описание образов и источников](stories/jurassic_day/visual-sources.md). Это ученическая история по существующей вымышленной вселенной, без заявления об официальной связи с её правообладателями.

«Первый экстрим» Ромы - фанатская история о Geometry Dash, созданной RobTop Games. Уровни принадлежат своим авторам; иллюстрации представляют художественную интерпретацию их мотивов. Исследование сленга, названий и отсылок приведено в [разборе истории](stories/first_extreme/RESEARCH.md).
